# Telegram-бот для учета рабочего времени сотрудников

Полнофункциональный Telegram-бот для учета рабочего времени сотрудников с интеграцией в рабочие чаты и возможностью экспорта отчетов в Excel.

## 🚀 Возможности

### Личный кабинет сотрудника:
- Регистрация при первом входе
- Просмотр своей информации (имя, ставка, баланс)
- Просмотр истории табелей
- Просмотр истории премий/штрафов
- Отправка ежемесячного табеля

### Админ-панель:
- Просмотр всех сотрудников
- Начисление премий и штрафов
- Настройка часовых ставок
- Просмотр и подтверждение табелей
- Генерация отчетов

### Система штрафов и премий:
- Ручное начисление админом
- Автоматический пересчет баланса
- История всех транзакций
- Комментарии к операциям

### Считывание часов по фото табеля:
- Прием фото от сотрудников
- Обработка через OCR (Tesseract)
- Распознавание количества часов
- Подтверждение/редактирование админом

### Интеграция в рабочий чат:
- Автоматическое подключение к чату по пригласительной ссылке
- Мониторинг сообщений в чате для команд
- Уведомления в чат о важных событиях
- Команды доступные прямо в групповом чате:
  - `/табель` - отправить табель
  - `/баланс` - посмотреть свой баланс
  - `/сотрудники` - просмотр сотрудников (только админы)
  - `/отчет` - сгенерировать отчет (только админы)

### Экспорт данных:
- Экспорт в Excel (.xlsx) с форматированием
- Экспорт в CSV для совместимости
- Автоматическое формирование отчетов:
  - Месячный отчет по зарплатам
  - Отчет по отработанным часам
  - Финансовый отчет (премии/штрафы)
  - Статистика по сотрудникам

## 🛠 Технологии

- Python 3.8+
- Aiogram 3.x для Telegram бота
- SQLite/PostgreSQL для базы данных
- Tesseract OCR для распознавания текста
- OpenCV/Pillow для обработки изображений
- Pandas для обработки данных и экспорта
- Openpyxl для создания Excel файлов
- APScheduler для планирования задач

## 📋 Установка

### 1. Клонирование репозитория
```bash
git clone <ваш_репозиторий>
cd <папка_бота>
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Установка Tesseract OCR

**Для Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install tesseract-ocr
sudo apt install libtesseract-dev
```

**Для Windows:**
1. Скачайте и установите Tesseract с официального сайта: https://github.com/UB-Mannheim/tesseract/wiki
2. Добавьте путь к установленному tesseract в переменные среды (например: `C:\Users\YourName\AppData\Local\Tesseract-OCR\tesseract.exe`)

**Для macOS:**
```bash
brew install tesseract
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_бота_от_BotFather
ADMIN_IDS=123456789,987654321
TESSERACT_PATH=/usr/bin/tesseract  # Путь к tesseract (необязательно для Windows)
EXPORT_DIR=./exports
DATABASE_URL=sqlite:///employees.db
WORK_CHAT_ID=-1001234567890  # ID рабочего чата (опционально)
```

### 5. Запуск бота

```bash
python bot.py
```

## ⚙️ Настройка бота

### Создание бота через @BotFather
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Скопируйте токен и вставьте его в `.env` файл как `BOT_TOKEN`

### Добавление бота в рабочий чат
1. Добавьте бота в ваш рабочий чат как обычного участника
2. Сделайте бота администратором с правами:
   - Просмотр сообщений
   - Отправка сообщений
   - Прикрепление сообщений (опционально)

### Настройка администраторов
В файле `.env` укажите ID Telegram аккаунтов, которые будут администраторами бота:
```
ADMIN_IDS=123456789,987654321
```

## 📖 Использование

### Для сотрудников:
1. Напишите боту `/start` для регистрации
2. Укажите ваше ФИО и должность
3. Используйте кнопки в меню для навигации
4. Для отправки табеля: нажмите "⏰ Отправить табель" и пришлите фото

### Для администраторов:
1. После регистрации у вас появятся дополнительные кнопки в меню
2. Можете управлять сотрудниками, начислять премии/штрафы
3. Подтверждать табели сотрудников
4. Генерировать отчеты

### В рабочем чате:
- Используйте команды `/баланс`, `/табель` и другие прямо в чате
- Администраторы могут использовать `/сотрудники` и `/отчет`

## 📊 Отчеты

Бот автоматически генерирует различные отчеты:
- Месячные отчеты по зарплатам
- Отчеты по отработанным часам
- Финансовые отчеты (премии/штрафы)
- Полные отчеты со всеми данными

Отчеты сохраняются в папке `exports` в формате Excel с форматированием.

## 🔧 Возможные проблемы и решения

### OCR не распознает часы
- Убедитесь, что на фото четко видны цифры
- Попробуйте сделать фото при хорошем освещении
- Используйте четкие, крупные цифры

### Ошибки при работе с базой данных
- Проверьте права доступа к файлу базы данных
- Убедитесь, что в системе достаточно места

### Проблемы с правами бота в чате
- Убедитесь, что бот добавлен как администратор
- Проверьте, что у бота есть права на чтение сообщений
